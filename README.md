APS – Criptografia

Trabalho da disciplina de Atividades Práticas Supervisionadas (APS) do curso de Sistemas de Informação – Universidade Paulista (UNIP), Campinas/SP, 2025.

Sobre o projeto

Uma página web didática que explica o que é criptografia e traz uma ferramenta para criptografar e descriptografar mensagens com três cifras clássicas:

Cifra	Como funciona	Parâmetro
César	Desloca cada letra do alfabeto um número fixo de posições.	Número (ex.: 3)
Vigenère	Evolução da César: cada letra da chave define um deslocamento diferente.	Palavra-chave só com letras (ex.: CHAVE)
Transposição	Mantém as letras, mas embaralha suas posições a partir da chave.	Palavra-chave (ex.: CHAVE)

Exemplo (César, deslocamento 3): ATAQUE → DWDTXH

Como usar
Baixe o arquivo criptografia.html (botão Code → Download ZIP, ou abra o arquivo no GitHub e clique em Download raw file).
Dê dois cliques no arquivo. Ele abre no navegador, sem instalar nada.
Na seção Ferramenta Prática, escolha o método, digite o texto e o parâmetro, e clique em Criptografar ou Descriptografar.
Tecnologias

HTML, CSS e JavaScript puros, em um único arquivo. Desenvolvido no VS Code.
